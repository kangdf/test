# AGENT_market-monitor

## Alice Chat
`Alice Chat/market-monitor.json`为 SubAgent 配置文件，配套`Alice Chat/skill/`、`Alice Chat/schemas/alert_subscribe.json`。固定版本参数为 15。

## AliceWeb
`AliceWeb/market-monitor.json`为 SubAgent 配置文件，配套`AliceWeb/skill/`、`AliceWeb/schemas/alert_subscribe.json`。固定版本参数为 17。

两个目录分别上传到对应平台，不要混淆。
